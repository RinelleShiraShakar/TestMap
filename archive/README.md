# Архив сборок игровой карты Ойкумены

Здесь хранятся старые сборки карты. Новые сборки делает тред «Сборка карты»; сюда попадают снятые с использования или зафиксированные версии.

## Порядок
- Каждая сборка лежит в своей папке `builds/ГГГГ-ММ-ДД_краткое-имя/` и открывается как есть (`index.html` в папке).
- В папке есть `SHA256SUMS`: по нему проверяются дубли. Одинаковая сборка второй раз не кладётся.
- Копия архива лежит в репозитории GitHub `RinelleShiraShakar/TestMap`, папка `archive/`. Эталон там: при записи в папку проекта к картинкам добавляются метаданные C2PA, пиксели не меняются, но контрольные суммы jpg/png здесь не сходятся. Дубли картинок сверять по пикселям или по копии в репозитории.
- Новые сборки добавляются в таблицу ниже, сверху самые свежие.
