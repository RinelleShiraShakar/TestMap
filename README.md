# Карта Ойкумены

Текущая сборка: v2 (2026-10-10), собрана с нуля. Открывается файлом `index.html` или на странице https://rinelleshirashakar.github.io/TestMap/

- `index.html` — интерфейс карты
- `data.js` — данные (государства, провинции, поселения, тракты, персонажи), собраны скриптами из `tools/`
- `base.jpg`, `phys.jpg`, `regions.png` — подложки и маска регионов
- `img/` — портреты персонажей и гербы

Прежние сборки лежат в `archive/` (первая — «Атлас Ойкумены», `archive/builds/2026-10-10_atlas-v1/`).
